19. (17分) 设函数 $y=ax^2+(1-a)x+a-2$ ($a\in R$)
(1) 若关于 $x$ 的不等式的 $y\leq 0$ 解集为 $\{x\mid 0\leq x\leq b\}$，求实数 $a$，$b$ 的值；
(2) 解关于 $x$ 的不等式：$y<a-1$。

### 手写答案

(1) $0$ 和 $b$ 是方程 $ax^2+(1-a)x+a-2$ 的根
且 $a>0$
$\therefore 0+b=-\frac{1-a}{a}$
$0\times b=\frac{a-2}{a}$
解得 $a=2$，$b=\frac{1}{2}$。
(2) 由 $f(x)<a-1$ 则 $ax^2+(1-a)x-1<0$。
当 $a=0$ 时，不等式可化简为 $x-1<0$，$x<1$，$\{x\mid x<1\}$
当 $a<0$ 时，不等式可化为 $(x+\frac{1}{a})(x-1)>0$。
① 当 $a=-1$ 时，$-\frac{1}{a}=1$，不等式的解集为 $\{x\mid x\neq 1\}$。
② 当 $-1<a<0$ 时，$-\frac{1}{a}>1$，不等式的解集为 $\{x\mid x<1 \text{ 或 } x>-\frac{1}{a}\}$。
③ 当 $a<-1$ 时，$-\frac{1}{a}<1$，不等式的解集为 $\{x\mid x<-\frac{1}{a} \text{ 或 } x>1\}$。
综上 当 $a<-1$ 时 $\Rightarrow \{x\mid x<-\frac{1}{a} \text{ 或 } x>1\}$
当 $a=-1$ 时 $\Rightarrow \{x\mid x\neq 1\}$
当 $-1<a<0$ 时 $\Rightarrow \{x\mid x<1 \text{ 或 } x>-\frac{1}{a}\}$
当 $a=0$ 时 $\Rightarrow \{x\mid x<1\}$
当 $a>0$ 时 $\Rightarrow \{x\mid -\frac{1}{a}<x<1\}$

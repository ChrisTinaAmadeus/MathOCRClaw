18. (17分) 已知关于 $x$ 的不等式 $(ax-1)(x+1)>0$.
(1) 若此不等式的解集为 $\left\{x \mid -1 < x < -\frac{1}{2}\right\}$，求实数 $a$ 的值；
(2) 若 $a \in \mathbf{R}$，解这个关于 $x$ 的不等式；
(3) 已知 $y_1 = 4x_1^2 + 3$，$y_2 = ax_2 + 5 - a (a>0)$，若对任意的 $x_1 \in \{x \mid 1 \le x \le 2\}$，总存在 $x_2 \in \{x \mid -1 \le x \le 2\}$，使得 $y_1 = y_2$ 成立，求实数 $a$ 的取值范围.

### 手写答案

(1) 由题可知 $-1, -\frac{1}{2}$ 为方程的两根.
可得 $\frac{1}{a} = -\frac{1}{2}$，即 $a=-2$.

(2) 当 $a=0$ 时，$-x-1>0$.
当 $a<0$ 时. ① $a=-1$. $\varnothing$
② $a<-1, \frac{1}{a} > -1$. $\left\{x \mid -1 < x < \frac{1}{a}\right\}$
③ $-1 < a < 0, \frac{1}{a} < -1$. $\left\{x \mid \frac{1}{a} < x < -1\right\}$.

(3) 当 $x_1 \in \{x \mid 1 \le x \le 2\}$ 时，则 $\{y_1\}$ 使 $y_1 \in [7, 19]$.
$\because y_1 = y_2$.
$\therefore y_{2\max} = 19, y_{2\min} = 7$.
$\because x_2 \in \{x \mid -1 \le x \le 2\}$.
$\therefore y_{2\max} = 2a + 5 - a = a + 5$.
$y_{1\min} = -a + 5 - a = -2a + 5$.
$\therefore \begin{cases} a+5 \ge 19 & a \ge 14 \\ -2a+5 \le 7 & a \ge -1 \end{cases}$
综上，$a$ 的取值范围为 $\{a \mid a \ge 14\}$.

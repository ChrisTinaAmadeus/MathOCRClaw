3. 已知事件 $A$、$B$ 相互独立，事件 $A$ 发生的概率为 $P(A)=\frac{1}{2}$，事件 $B$ 发生的概率为 $P(B)=\frac{1}{2}$，则“两个事件 $A$，$B$ 至少有一个发生”的概率为 ( )

C. $\frac{3}{4}$

15. (本小题满分 13 分) 已知集合 $A=\left\{x \mid \frac{2-x}{x+2}>0\right\}$，$B=\{x \mid |x-1|>2\}$，$C=\{x \mid m-1<x<2m+1\}$。
(1) 求 $A \cap B$，$(\complement_R B) \cup A$；
(2) 若 $A \cap C=C$，求实数 $m$ 的取值范围。

### 手写答案

解：$A=\{x \mid -2<x<2\}$
$\therefore A=\{x \mid -2<x<2\}$
$B=\{x \mid |x-1|>2\}$
$\therefore B=\{x \mid x<-1 \text{或} x>3\}$
$\therefore A \cap B=\{x \mid -2<x<-1\}$
$(\complement_R B)=\{x \mid -1 \le x \le 3\}$
$(\complement_R B) \cup A=\{x \mid -2<x \le 3\}$
(2) $\because A \cap C=C$
$\therefore C \subseteq A$
1. 当 $C$ 为空集时 $m-1 \ge 2m+1 \Rightarrow m \le -2$
2. 若 $C$ 不为空集时 $\begin{cases} m>-2 \\ m-1 \ge -2 \Rightarrow m \ge -1 \\ 2m+1 \le 2 \Rightarrow m \le \frac{1}{2} \end{cases}$
即 $-1<m<\frac{1}{2}$
综上，$m$ 的取值范围为 $m \le -2$ 或 $-1<m<\frac{1}{2}$。

16. (本小题满分 15 分) 已知 $a \in \mathbf{R}$，$p: \forall x \in \{x \mid 0 \le x \le 1\}, a \le x^2+1$；$q: \exists x_0 \in \mathbf{R}, x_0^2+2ax_0-(2a-3)=0$。
(1) 若 $p$ 是真命题，求 $a$ 的最大值；
(2) 若 $p$ 为假命题且 $q$ 为真命题，求 $a$ 的取值范围。

### 手写答案

解：(1) $\because p$ 为真命题
$\therefore$ 当 $x=1$ 时 $x^2+1$ 最大，此时 $x^2+1=2$
$\therefore$ 有 $a \le 2$
即 $a_{\max}=2$
(2) $\because p$ 为假命题
$\therefore \exists x \in \{x \mid 0 \le x \le 1\}, a>x^2+1$
$\therefore a>1$
$\therefore a>2$
$\because q$ 为真命题
$\therefore$ 存在方程 $x_0^2+2ax_0-(2a-3)=0$，
$\Delta=4a^2+4(2a-3)>0$
即 $4a^2+8a-12>0$
解得 $a<-3$ 或 $a>1$
综上 $a$ 的取值范围为 $a \le -3$ 或 $a>2$。

17. (本小题满分 15 分) (1) 已知 $0<x<2$，$0<y<3$，求 $2x-y$ 的取值范围；
(2) 已知 $x>3$，求 $y=2x+\frac{4}{2x-6}$ 的最小值；
(3) 若 $0<x<4$，求 $y=x(8-2x)$ 的最大值。

### 手写答案

解：(1) $\because 0<x<2$
$\therefore 0<2x<4$
$\because 0<y<3$
$\therefore -3<-y<0$
$\therefore -3<2x-y<4$
(2) $\because x>3$
$\therefore x-3>0$
$\therefore 2x-6>0$
$y=2x+\frac{4}{2x-6}=2x-6+\frac{4}{2x-6}+6$
$\ge 2\sqrt{(2x-6) \cdot \frac{4}{2x-6}}+6=10$
当且仅当 $2x-6=\frac{4}{2x-6}$ 时，等号可取
$\therefore (2x+\frac{4}{2x-6})_{\min}=10$
(3) $y: 0<x<4$
$\therefore 4-x>0$
$8-2x>0$
$x(8-2x)=\frac{1}{2} \cdot 2x(8-2x)$
$\le \frac{1}{2}\left(\frac{2x+8-2x}{2}\right)^2=8$
$\therefore x(8-2x) \le 8$
$x(8-2x)_{\max}=8$

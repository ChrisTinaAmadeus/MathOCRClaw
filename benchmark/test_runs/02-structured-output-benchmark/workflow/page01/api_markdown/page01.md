19. (12分)
如图，$PA \perp$ 平面 $ABCD$，四边形 $ABCD$ 为矩形，$PA=AB=2$，$AD=4$，点 $F$ 是 $PB$ 的中点，点 $E$ 在边 $BC$ 上移动。
<插图>
(1) 求三棱锥 $E-PAD$ 的体积；
(2) 证明：$AF \perp PE$。

### 手写答案

(1) 解：$PA=AB=2, AD=4$
$S_{\triangle PAD}=2\times 4\div 2=4$
$\therefore h=2$
$\therefore V_{E-PAD}=\frac{1}{3}Sh=\frac{1}{3}\times 4\times 2=\frac{8}{3}$

(2) 证明：$PA \perp$ 平面 $ABCD$
$AB, CB \subset$ 平面 $ABCD$
$PA \perp BC$
$\triangle PAB$ 为等腰三角形
$F$ 为 $PB$ 中点
$AF \perp BP$
如图所示建空间直角坐标系，$A$ 为原点
$PA=AB=2, AD=4$
$P(0,0,2), C(4,2,0), A(0,0,0), F(0,1,1)$
$\overrightarrow{PC}=(4,2,-2), \overrightarrow{AF}=(0,1,1)$
$\cos\theta=\frac{\overrightarrow{PC}\cdot \overrightarrow{AF}}{|\overrightarrow{PC}||\overrightarrow{AF}|}=0$
$PC \perp AF$
$PB, PC \subset$ 平面 $PBC, PB \cap PC=P$
$AF \perp$ 平面 $PBC$
$PE \subset$ 平面 $PBC \therefore PE \perp AF$

16. （15分）如图，在平行六面体 $ABCD-A_1B_1C_1D_1$ 中，$E, F$ 分别为棱 $A_1D_1, CD$ 的中点，满足 $\angle B_1BC = \angle B_1BA = \frac{\pi}{3}, \angle CBA = \frac{\pi}{2}, |AB|=|BC|=2, |BB_1|=3$。
<插图>
(1) 求证：$EF // 平面 BDA_1$；
(2) 求 $BD_1$ 的长度；
(3) 求 $AC$ 与 $EF$ 夹角的余弦值。

### 手写答案

(1) 如图连接 $A_1B, BD$，设 $BD$ 中点为 $G$，连接 $A_1G, GF$。
这是一个平行六面体。
$A_1D_1 // BC$，$G, F$ 分别是 $BD, CD$ 的中点。
$GF \underline{\underline{//}} \frac{1}{2} BC$。
$E$ 是 $A_1D_1$ 的中点，$\therefore A_1E \underline{\underline{//}} \frac{1}{2} BC$。
$\therefore A_1E // GF$。
四边形 $A_1EFG$ 为平行四边形 $\therefore A_1G // EF$。
$EF \not\subset 平面 BDA_1, A_1G \subset 平面 BDA_1 \therefore EF // 平面 BDA_1$。
(2) $\overrightarrow{BD_1} = \overrightarrow{BA} + \overrightarrow{BC} + \overrightarrow{BB_1}$
$\overrightarrow{BD_1}^2 = \overrightarrow{BA}^2 + \overrightarrow{BC}^2 + \overrightarrow{BB_1}^2 + 2\overrightarrow{BA}\cdot\overrightarrow{BC} + 2\overrightarrow{BA}\cdot\overrightarrow{BB_1} + 2\overrightarrow{BC}\cdot\overrightarrow{BB_1}$
$= 4+4+9+0+2\times 2\times 3\times \frac{1}{2} \times 2 = 29$
$BD_1 = \sqrt{29}$
(3) $\overrightarrow{AC} = \overrightarrow{BC} - \overrightarrow{BA}$，$\overrightarrow{EF} = \frac{1}{2}\overrightarrow{BA} + \frac{1}{2}\overrightarrow{BC} - \overrightarrow{BB_1}$
$|\overrightarrow{AC}| = \sqrt{8}, |\overrightarrow{EF}| = \sqrt{11}$
$|\overrightarrow{AC} \cdot \overrightarrow{EF}| = 4$
$\frac{\sqrt{22}}{11}$

一、单选题

1. 命题“$\exists x \in \mathbf{R}, x^2+1>0$”的否定是（ ）
A. $\forall x \in \mathbf{R}, x^2+1>0$
B. $\exists x \in \mathbf{R}, x^2+1 \le 0$
C. $\forall x \in \mathbf{R}, x^2+1 \le 0$
D. $\exists x \in \mathbf{R}, x^2+1<0$

### 手写答案

C

2. 已知 $x<0, 0<y<1$，则（ ）
A. $\frac{x}{y^2} < \frac{x}{y} < x$
B. $\frac{x}{y} < x < \frac{x}{y^2}$
C. $x < \frac{x}{y} < \frac{x}{y^2}$
D. $xy^2 < x < xy$

### 手写答案

C

3. 已知函数 $f(x)=\begin{cases} x+1, x \le 2 \\ 2f(x-1), x > 2 \end{cases}$，则 $f(3)=$（ ）
A. 3
B. 4
C. 6
D. 8

### 手写答案

A. $(-\infty, 2]$
B. $[2, +\infty)$

D. $x \in \{x \mid 1 \le x \le 3\}$

二、多选题

9. 在生产生活中，人们常用十进制计数，而本福特定律说明在 $b$ 进制中，以数字 $n(n \le b-1)$ 起头的数出现的概率为 $\log_b \frac{n+1}{n}$，此定律可用于检查数据造假等问题。现定义 10-本福特函数 $B(x)=\lg \frac{x+1}{x}$，则（ ）
A. $B(2)$ 表示十进制中以数字 2 起头的数出现的概率
B. 曲线 $y=B(x)$ 关于点 $(-\frac{1}{2}, 0)$ 对称
C. $B(n)<\frac{1}{2} (n=1, 2, \cdots, 9)$
D. $B(2) \ge 2B(4)$

### 手写答案

AC

10. 已知 $f(x), g(x)$ 分别是定义在 $\mathbf{R}$ 上的偶函数和奇函数，且 $f(x)-g(x)=e^x$，则下列说法正确的是（ ）
A. $[g(x)]^2-[f(x)]^2=1$
B. $g(2x)=2f(x)g(x)$
C. 若 $g(t-2)+g(2t)>0$，则 $t>1$
D. 方程 $f(x)=m$ 有两个不相等的实数根，则 $m>1$

### 手写答案

B

14. 直角坐标平面内两点 $P, Q$ 满足条件：
(1) $P, Q$ 都在函数 $f(x)$ 的图象上；
(2) $P, Q$ 关于原点对称，则称点对 $(P, Q)$ 是函数 $f(x)$ 的一个“友好点对”（点对 $(P, Q)$ 与点对 $(Q, P)$ 看作同一个“友好点对”）。
已知函数 $f(x)=\begin{cases} \frac{1}{2}x-\ln(e^x+1), x \le 0 \\ -ax^2+(2a-\frac{1}{2})x+e-a, x > 0 \end{cases} (a>0)$ 存在两个“友好点对”，则 $a$ 的取值范围为 ______

### 手写答案

$(e, e^2)$

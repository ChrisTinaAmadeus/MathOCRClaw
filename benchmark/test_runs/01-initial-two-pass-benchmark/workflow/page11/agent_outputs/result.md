### 手写答案

(1) 证明：
$\because$ 三棱台 $ABC-A_1B_1C_1$
且 $A_1A \perp$ 平面 $ABC$.
$\therefore A_1C_1 // AC$.
$\because A_1C_1 = \frac{1}{2} AC$
$\therefore A_1C_1 \underline{\underline{\parallel}} \frac{1}{2} AC$.
$\because M, N$ 分别为 $BC, AB$ 中点，$\therefore MN$ 为三角形 $ABC$ 中位线
$\therefore MN \underline{\underline{\parallel}} \frac{1}{2} AC$
$\therefore MN \underline{\underline{\parallel}} A_1C_1$
$\therefore$ 四边形 $A_1C_1MN$ 是平行四边形
$\therefore A_1N // C_1M$
$\because A_1N \not\subset$ 平面 $C_1MA, C_1M \subset$ 平面 $C_1MA$.
$\therefore A_1N //$ 平面 $C_1MA$.

(2) $\because A_1A \perp$ 平面 $ABC, AB \perp AC. AB=AC=AA_1=2, A_1C_1=1$
$\therefore$ 以 $A$ 为原点，以 $AB, AC, AA_1$ 所在直线为 $x, y, z$ 轴建系.
$\therefore C_1(0, 1, 2) \quad M(1, 1, 0) \quad A(0, 0, 0)$
$\therefore \overrightarrow{AC_1} = (0, 1, 2) \quad \overrightarrow{AM} = (1, 1, 0)$
设平面 $C_1MA$ 的一个法向量为 $\vec{n} = (x, y, z)$，则有 $\begin{cases} \vec{n} \cdot \overrightarrow{AC_1} = 0 \\ \vec{n} \cdot \overrightarrow{AM} = 0 \end{cases}$
$\therefore \vec{n} = (2, -2, 1)$ 是平面 $C_1MA$ 的一个法向量.
$\because AB \perp$ 平面 $ACC_1A_1$ $\therefore \overrightarrow{AB} = (1, 0, 0)$ 是平面 $ACC_1A_1$ 的一个法向量
记平面 $C_1MA$ 与平面 $ACC_1A_1$ 所成角为 $\theta$.
则：$\cos\theta = |\cos<\vec{n}, \overrightarrow{AB}>| = \frac{2}{3}$.
$\therefore$ 平面 $C_1MA$ 与平面 $ACC_1A_1$ 所成角的余弦值为 $\frac{2}{3}$.

(3) 由 (2) 知：$\vec{n} = (2, -2, 1)$ 是平面 $C_1MA$ 的一个法向量.
$C(0, 2, 0) \quad A(0, 0, 0) \quad \overrightarrow{AC} = (0, 2, 0)$
设点 $C$ 到平面 $C_1MA$ 的距离为 $d$. 则：
$d = \frac{|\overrightarrow{AC} \cdot \vec{n}|}{|\vec{n}|} = \frac{4}{3}$.

# API2 原子补丁协议：负样本复盘与验证报告

日期：2026-08-26

## 1. 结论

`20260826-145133` 的 32 页结果为 API1 `85.65`、API2 `83.99`，API2 相对 API1 降低 `1.67` 分。逐页核对后可以确认，主要问题不是 API2 看不到局部图像，而是旧接口要求 API2 返回整页最终 JSON，使它拥有重写完整题干和完整解答的权限；随后本地 lint 只能在模型已经改写之后被动猜测哪些变化应回滚。

本轮把 API2 改为 `api2_patch_v2`：API1 是权威底稿，API2 只返回逐题审查结果和高置信原子补丁。本地合并器逐项验证旧子串唯一、证据与上下文有效、LaTeX 和题目结构不退化之后才应用。选择题和填空题可以提交结构化最终答案；解答题不得自由重写全文，只能提交局部精确替换。

## 2. 上一轮更新及其边界

上一轮记录见 `20260825-workflow-fix-validation.zh-CN.md`。当时已经完成：

1. 选择、填空、解答题统一输出契约，并引入 `answer_parts`；

## 4. API2 交付协议重新设计

### 4.1 模型输出职责

API2 现在返回 `schema_version=api2_patch_v2` 和与 API1 题目一一对应的 `question_reviews`：

- `stem.action` 只能是 `keep` 或 `edit`；
- `answer.action` 只能是 `keep`、`replace_choice`、`replace_fill`、`edit_solution` 或 `set_no_answer`；
- 题干和解答题修改必须写成 `{old,new,kind,confidence,context_id,evidence}` 精确子串替换；
- 默认动作是 `keep`，禁止返回完整题干或完整解答的替代版本；
- 禁止省略号、`see full text`、摘要和“同上”等编辑性占位；
- 所有高置信修改必须绑定已发送的视觉上下文并给出可核对证据；
- 学生笔迹中的坐标轴、辅助线和几何草图不得当成印刷题图。

API2 请求中不再同时发送“整页 Markdown + 每题重复全文”，而是把每个 API1 字段只放在对应的本地题目上下文中，降低长上下文重复和自由重写诱因。

### 4.2 本地确定性门控

本地只应用同时满足以下条件的补丁：

1. `confidence=high`，证据非空，`context_id` 有效；
2. `old` 在 API1 原字段中恰好出现一次；
3. 修改不是整字段替换，也没有超过局部补丁长度限制；
4. 不引入编辑性截断，LaTeX 定界符保持平衡；
5. 不删除选项、小问、圈号或公式结构；
6. 解答题公式 span 不减少，除非补丁明确删除视觉上已经作废的内容；
7. API1 有受支持答案时，API2 不得用 `set_no_answer` 删除它；
8. `<插图>` 只有在高置信、带视觉证据的原子题干补丁中才允许删除，其他结构减少仍回滚。

题型判定也同步收紧：检测选项前先剥离 LaTeX，避免集合公式中的 `A)`、`B)` 触发选择题；识别转义横线 `\_\_\_` 作为填空结构；章节标题和 API1 题型优先于 API2 自报题型。

### 4.3 无答案状态

填空题的 `_未识别到手写答案。_` 不再被 `$...$` 包裹。填空或解答题的全部结构化小问均为 `no_answer` 时，评分候选只形成一个“无受支持答案”状态，不再把多个占位符计为幻觉。

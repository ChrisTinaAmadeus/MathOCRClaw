### 手写答案

(1) 证明：∵在正方形$ADEF$中，
∴ $ED \perp AD$
又∵ $DE \perp CD$
$CD \cap AD = D$
$CD, AD \subset$ 面$ABCD$
∴ $DE \perp$ 面$ABCD$
∵ $DE \subset$ 面$ADEF$
∴ 面$ADEF \perp$ 面$ABCD$

(2) 解：根据题意得 $AD=AF=EF=4$,
$CD=2$
∵ $AF \perp AD, AD =$ 面$ADEF \cap$ 面$ABCD$
$AF \subset$ 面$ADEF$
 $AF \perp$ 面$ADCB$
∴ $AF \perp AB$
∵ $BF$与面$ABCD$所成角为$45^{\circ}$
∴ $AB = \tan 45^{\circ} \cdot AF = 4$
∵ $CD // AB, \angle CDA = 90^{\circ}$
∴ 四边形$ABCD$是直角梯形
∴ $S_{\text{梯形}ABCD} = \frac{1}{2}(CD+AB) \cdot AD = 12$
$V_{\text{四棱锥}E-ABCD} = \frac{1}{3} S_{\text{梯形}ABCD} \cdot ED = 16$

(3) 解：∵ $BF$与面$ABCD$所成角为$45^{\circ}$
$CG // BF$与面$ABCD$所成角也为$45^{\circ}$
∴ $DG=CD=2$
$GF^2 = EG^2 + EF^2$
$CB^2 = AB^2 + \frac{1}{4} AB^2$
∵ $EF // AD, EG = \frac{1}{2} AB$
∴ 四边形$CBFG$为等腰梯形
作$GH \perp BF$
$FH = \frac{BF-CG}{2} = 1$
$GH = \sqrt{FG^2 - FH^2} = \sqrt{19}$
∴ $S_{\text{四边形}CBFG} = \frac{1}{2}(CG+BF) \cdot GH = 3\sqrt{38}$

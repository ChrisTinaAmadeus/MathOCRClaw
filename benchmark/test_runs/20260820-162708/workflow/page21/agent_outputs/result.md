18. (17分)
(1) 设关于 $x$ 的方程 $tx^2 + (1-t)x + t - 1 = 0$ 有两个不相等的实数根 $x_1, x_2$.
① 求 $t$ 的取值集合；
② 若 $x_1^2 + x_2^2 = 3$，求 $t$ 的值.
(2) 求关于 $x$ 的不等式 $tx^2 + (1-t)x + t - 1 < 0$ ($t$ 为常数且 $t \in \mathbb{R}$) 的解集.

### 手写答案

$t \neq 0$

$\{x \mid -\frac{1}{3} < x < 1\}$

19. (17分)
已知 $a, b, c, d$ 均为正实数.
(1) 证明：$\frac{a^2}{c} + \frac{b^2}{d} \geqslant \frac{(a+b)^2}{c+d}$.
(2) 若 $a+2b=ab$，求 $\frac{4}{a^2+2a} + \frac{1}{2b^2+b}$ 的最小值.
(3) 若 $a+2b+3c=\sqrt{6}$，求 $a^2+8b^2+6c^2$ 的最小值.

### 手写答案

(1) 证1：$\frac{a^2}{c} + \frac{b^2}{d} - \frac{(a+b)^2}{c+d}$
$= \frac{a^2d(c+d) + b^2c(c+d) - (a+b)^2cd}{cd(c+d)}$
$= \frac{a^2cd + a^2d^2 + b^2c^2 + b^2cd - (a^2cd + 2abcd + b^2cd)}{cd(c+d)}$
$= \frac{a^2d^2 + b^2c^2 - 2abcd}{cd(c+d)}$
$= \frac{(ad-bc)^2}{cd(c+d)} \geqslant 0$. 当且仅当 $ad=bc$ 时.

(2) $\frac{(2/a)^2}{1+2/a} + \frac{(1/b)^2}{2+1/b} \geqslant \frac{(2/a+1/b)^2}{1+2/a+2+1/b}$
$\geqslant \frac{1}{4}$.

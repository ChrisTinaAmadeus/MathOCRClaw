18. (本小题满分 17 分) [无法识别]

### 手写答案

(1) 证明：
∵ 三棱台 ABC-A₁B₁C₁，且 A₁A ⊥ 平面 ABC.
∴ A₁C₁ // AC.
∵ A₁C₁ = ½AC
∴ A₁C₁ ∥= ½AC.
∵ M, N 分别为 BC, AB 中点 ∴ MN 为三角形 ABC 中位线
∴ MN ∥= ½AC ∴ MN ∥= A₁C₁ ∴ 四边形 A₁C₁MN 是平行四边形
∴ A₁N // C₁M ∵ A₁N ⊄ 平面 C₁MA，C₁M ⊂ 平面 C₁MA.
∴ A₁N // 平面 C₁MA.

(2) ∵ A₁A ⊥ 平面 ABC，AB ⊥ AC. AB=AC=AA₁=2，A₁C₁=1
∴ 以 A 为原点，以 AB, AC, AA₁ 所在直线为 x, y, z 轴建系.
∴ C₁(0,1,2) M(1,1,0) A(0,0,0)
∴ $\overrightarrow{AC_1} = (0,1,2)$，$\overrightarrow{AM} = (1,1,0)$
设平面 C₁MA 的一个法向量为 $\vec{n} = (x,y,z)$，则有 $\vec{n} \cdot \overrightarrow{AC_1} = 0$，$\vec{n} \cdot \overrightarrow{AM} = 0$
∴ $\vec{n} = (2,-2,1)$ 是平面 C₁MA 的一个法向量.
∵ AB ⊥ 平面 ACC₁A₁ ∴ $\overrightarrow{AB} = (2,0,0)$ 是平面 ACC₁A₁ 的一个法向量
记平面 C₁MA 与平面 ACC₁A₁ 所成角为 θ.
则：cosθ = |cos⟨$\vec{n}$, $\overrightarrow{AB}$⟩| = 2/3.
∴ 平面 C₁MA 与平面 ACC₁A₁ 所成角的余弦值为 2/3.

(3) 由 (2) 知：$\vec{n} = (2,-2,1)$ 是平面 C₁MA 的一个法向量.
C(0,2,0) A(0,0,0) $\overrightarrow{AC} = (0,2,0)$
记点 C 到平面 C₁MA 的距离为 d. 则：
d = |$\frac{\overrightarrow{AC} \cdot \vec{n}}{|\vec{n}|}$| = 4/3

16. [无法识别]

### 手写答案

(1) m=2，B = {x|1 ≤ x ≤ 5}，∁_R B = {x|x < 1 或 x > 5}；A = {x|x² - x ≤ 0} = {x|0 ≤ x ≤ 1}，∁_R A = {x|x < 0 或 x > 1}；(∁_R A) ∩ (∁_R B) = {x|x < 0 或 x > 5}
(2) x ∈ A 是 x ∈ B 的充分不必要条件，A ⫋ B；{m-1 ≤ 2m+1, m-1 < 0, 2m+1 > 1} 解得 {m ≥ -2, m < 1, m > 0}；综上所述，0 < m < 1

17. [无法识别]

### 手写答案

(1) S = 5x + 30c + 30×6 + 30 = 5x + 30c + 210 = 5x + 30·\frac{k}{5x+5} + 210 = 5x + \frac{6k}{x+1} + 210
(2) S = 5x + \frac{6k}{x+1} + 210 = 5x + 5 + \frac{6k}{x+1} + 210 - 5 = 5(x+1) + \frac{6k}{x+1} + 205；5(x+1) + \frac{6k}{x+1} \ge 2\sqrt{5(x+1) \cdot \frac{6k}{x+1}} = 2\sqrt{30k}；S \ge 2\sqrt{30k} + 205；当且仅当 5(x+1) = \frac{6k}{x+1}，即 x_1 = \frac{\sqrt{30k}+5}{5}（舍），x_2 = \frac{\sqrt{30k}-5}{5}，S 取“=”，其最小值为 2\sqrt{30k} + 205

18. (本小题满分 17 分)
已知 △ABC 是边长为 4 的等边三角形，E, F 分别是 AB, AC 的中点，将 △AEF 沿着 EF 翻折，得到四棱锥 A₁-BCFE，平面 A₁EF ⊥ 平面 BCFE，平面 A₁EF ∩ 平面 A₁BC = l。
(1) 求证：l // 平面 BCFE；
(2) 求直线 BC 与平面 A₁BE 所成角的正弦值；
(3) 求点 C 到平面 A₁BE 的距离。

### 手写答案

(1) ∵ EF // BC，EF ⊂ 平面 A₁EF，BC ⊄ 平面 A₁EF，∴ BC // 平面 A₁EF；∵ BC ⊂ 平面 A₁BC，平面 A₁BC ∩ 平面 A₁EF = l，∴ BC // l；∵ BC ⊂ 平面 BCFE，l ⊄ 平面 BCFE，∴ l // 平面 BCFE
(2) 以 EF 中点 O 为原点，OD, OF, OA₁ 为轴；B(√3, -2, 0)，C(√3, 2, 0)，BC = (0, 4, 0)，A₁(0, 0, √3)，E(0, -1, 0)，A₁E = (0, -1, -√3)，A₁B = (√3, -2, -√3)；设 n 是平面 A₁BE 的一个法向量，∴ n = (1, √3, -1)，sinθ = |cos⟨n, BC⟩| = √15/5 [模糊]

19. (本小题满分 17 分)

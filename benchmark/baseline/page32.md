19. (17分) 设函数 $y=ax^2+(1-a)x+a-2(a \in \mathbf{R})$
(1) 若关于 $x$ 的不等式 $y \le 0$ 解集为 $\{x|0 \le x \le b\}$，求实数 $a, b$ 的值；
(2) 解关于 $x$ 的不等式：$y < a-1$.

### 手写答案

(1) $a=2, b=\frac{1}{2}$
0 和 $b$ 是方程 $ax^2+(1-a)x+a-2=0$ 的根，且 $a>0$.
$\therefore \begin{cases} 0+b = -\frac{1-a}{a} \\ 0 \times b = \frac{a-2}{a} \end{cases}$
解得 $a=2, b=\frac{1}{2}$.

(2) 由 $f(x) < a-1$ 则 $ax^2+(1-a)x-1 < 0$.
当 $a=0$ 时，不等式可化简为 $x-1 < 0 \Rightarrow x < 1$，解集为 $\{x|x<1\}$.
当 $a<0$ 时，不等式化为 $(x+\frac{1}{a})(x-1) > 0$.
① 当 $a=-1$ 时，$-\frac{1}{a}=1$，不等式的解集为 $\{x|x \ne 1\}$.
② 当 $-1 < a < 0$ 时，$-\frac{1}{a} > 1$，不等式的解集为 $\{x|x < 1 \text{ 或 } x > -\frac{1}{a}\}$.
③ 当 $a < -1$ 时，$-\frac{1}{a} < 1$，不等式的解集为 $\{x|x < -\frac{1}{a} \text{ 或 } x > 1\}$.
综上：
当 $a < -1$ 时 $\Rightarrow \{x|x < -\frac{1}{a} \text{ 或 } x > 1\}$.
当 $a = -1$ 时 $\Rightarrow \{x|x \ne 1\}$.
当 $-1 < a < 0$ 时 $\Rightarrow \{x|x < 1 \text{ 或 } x > -\frac{1}{a}\}$.
当 $a = 0$ 时 $\Rightarrow \{x|x < 1\}$.
当 $a > 0$ 时 $\Rightarrow \{x|-\frac{1}{a} < x < 1\}$.

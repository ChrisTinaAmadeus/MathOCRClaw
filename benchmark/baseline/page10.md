16. [无法识别]

### 手写答案

(1) $m=2$，$B = \{x|1 \le x \le 5，m \in \mathbb{R}\}$，$\complement_{\mathbb{R}} B = \{x|x < 1 \text{ 或 } x > 5\}$；$A = \{x|x^2 - x \le 0\} = \{x|0 \le x \le 1\}$，$\complement_{\mathbb{R}} A = \{x|x < 0 \text{ 或 } x > 1\}$；$(\complement_{\mathbb{R}} A) \cap (\complement_{\mathbb{R}} B) = \{x|x < 0 \text{ 或 } x > 5\}$
(2) $x \in A$ 是 $x \in B$ 的充分不必要条件，$A \subsetneq B$；$\{m-1 \le 2m+1, m-1 < 0, 2m+1 > 1\}$ 解得 $\{m \ge -2, m < 1, m > 0\}$；综上所述，$0 < m < 1$

17. [无法识别]

### 手写答案

(1) $S = 5x + 30c + 30 \times 6 + 30 = 5x + 30c + 210 = 5x + 30 \cdot \frac{k}{5x+5} + 210 = 5x + \frac{6k}{x+1} + 210$
(2) $S = 5x + \frac{6k}{x+1} + 210 = 5x + 5 + \frac{6k}{x+1} + 210 - 5 = 5(x+1) + \frac{6k}{x+1} + 205$；$5(x+1) + \frac{6k}{x+1} \ge 2\sqrt{5(x+1) \cdot \frac{6k}{x+1}} = 2\sqrt{30k}$；$S \ge 2\sqrt{30k} + 205$；当且仅当 $5(x+1) = \frac{6k}{x+1}$，即 $x_1 = \frac{\sqrt{30k}+5}{5}$（舍），$x_2 = \frac{\sqrt{30k}-5}{5}$，$S$ 取"$=$"，其最小值为 $2\sqrt{30k} + 205$

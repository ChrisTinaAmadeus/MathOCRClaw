# Benchmark 提取提示词

当前工作流第一次 API 调用的唯一提示词来源是 [`extract_v2.txt`](extract_v2.txt)。工作流直接读取该文件，不在 Python 代码中维护副本。

## 固定输出契约

- 每题以行首 `数字. ` 开始；
- 每题恰有一个 `### 手写答案`；
- 数学表达式使用 `$...$` 或 `$$...$$`；
- 插图统一写成 `<插图>`；
- 无法识别或无作答写 `_未识别到手写答案。_`；
- 整段可见笔迹完全无法辨认时写 `[无法识别]`，不使用 `[模糊]`；
- 被划去、涂抹或删除线标记的作废内容必须完全省略，也不得输出“划去”等编辑说明；
- 全文只包含 Markdown 正文。

旧版 `extract_v1.txt` 已移除，避免运行时误用不符合金标准的规则。后续修改规则时应新增版本文件，并同步更新此处的当前版本指向。
